# 300 条普通词条对照结果

日期：2026-09-12。目标设备：骁龙 8 Gen 3、16GB RAM、1TB 存储。

这是接入应用前的离线闭集检索对照，不是自然语言翻译准确率，也不是 Android 性能验收。测试没有启动应用、模拟器或热重载。

## 测试集

- 从当前 `tag_catalog.db` 的普通类别 0（Danbooru）和 7（e621）中各固定抽取 75 个词条，共 150 个。
- 每个词条分别用词库已有的中文译文和英文规范名查询，共 300 条；不生成新译文、不调用翻译服务。
- 抽样由词条名 SHA-256 排序确定，包含 `untucked_shirt`、`shirt_tucked_in`、`no_socks`、`short_hair`、`closed_eyes` 等容易混淆的已知样例。
- 候选语料是相同的 54,879 个普通词条及已有英文名/中文译文；测试集固定哈希：`c89380205320a771e530c84288b1c1df66afc1f1c718794b2f643c167b7b67bc`。

## 字面基线与解释

同一测试集的字面基线为：中文标签 Top-1 `139/150（92.67%）`，Top-5/Top-20 `150/150`；英文规范名因 catalog 唯一约束为 `150/150`。因此语义模型的价值在于补足自然语言改写和标签缺失，不应替代已有精确/前缀搜索。

对这批已知标签，E5-base 相比 small 的中文 Top-1 低 1 条、英文 Top-1 高 8 条、Top-20 高 1 条；279MB 并没有全面胜出。此前独立自然语言样例中，base 能把“衬衫下摆不塞在裙子里”排第 1，但“shirt not tucked in”和“双眼闭合”仍会混淆相反标签。下一步应验证精细重排、否定作用域和独立留出集。

## 结论

当前不锁定任何模型直接上线。针对 16GB 骁龙 8 Gen 3，下一步候选优先级可以是 E5-base（效果优先）与 E5-small（延迟/体积基线），但必须先做 ARM 量化、真机 P50/P95、峰值内存、连续输入取消和发热测试。x86 的 ONNX CPU 结果不能当作骁龙 NPU 结果；QNN/HTP 需要单独的模型兼容性验证。

原始 JSON 及可复现实验位于 `tool/.tmp/semantic-search/benchmark-300/`；固定模型版本和文件 SHA-256 见 `models.json`。模型、缓存和报告均不随 APK 打包。
